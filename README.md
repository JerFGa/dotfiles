# ⚙️ Dotfiles & Linux Development Environment

Configuraciones personales y archivos de personalización (*dotfiles*) para un entorno de trabajo minimalista, altamente productivo y fluido sobre **Linux**.

---

## 🖥️ Componentes Incluidos

- **[Hyprland](https://hyprland.org/):** Compositor de ventanas en mosaico dinámico (*dynamic tiling Wayland compositor*) altamente fluido con animaciones suaves, layouts automáticos y atajos de teclado personalizados.
- **[Waybar](https://github.com/Alexays/Waybar):** Barra de estado altamente personalizable para compositores Wayland con soporte para monitoreo de hardware, batería, red, audio y workspaces activos.
- **[Zsh](https://www.zsh.org/):** Configuración de shell con plugins de autocompletado inteligente, resaltado de sintaxis, aliases útiles para Git y desarrollo, y prompt optimizado.

---

## 📂 Estructura

```text
dotfiles/
├── hypr/       # Configuración de Hyprland (monitores, keybindings, reglas de ventanas)
├── waybar/     # Estilos CSS y módulos JSON de la barra de estado
└── zshrc       # Configuración de Zsh, variables de entorno y alias
```
